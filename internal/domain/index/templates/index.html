Features

Everything your inbox needs,
nothing it doesn't.

Built for developers who live in the terminal. Grail keeps you in flow.

Full TUI — keyboard-first
Navigate your inbox with vim-style keybindings. No mouse. No context switching.
Read & compose
Render HTML emails as markdown, write replies in your $EDITOR of choice.
Search & filter
Full Gmail query syntax. Search by label, sender, date, attachment — all from the prompt.
OAuth2 — secure by default
Grail uses Google's official OAuth2 flow. Your credentials never touch our servers.
Built with Bubble Tea
Powered by the Charm ecosystem — Bubble Tea, Glamour, Lipgloss. Fast and composable.
Label management
Apply, remove, and create Gmail labels without touching a browser. Scriptable too.
How it works

Up in three steps.

From zero to inbox in under two minutes.

Install
Get the binary
Install via go install or grab a prebuilt release from GitHub.
Authenticate
Link your account
Run grail auth. Grail opens a browser once for the OAuth handshake, then stores the token locally.
Launch
Open your inbox
Run grail inbox. That's it. You're in.
Configure
Make it yours
Edit ~/.config/grail/config.toml to set keybinds, themes, and per-label rules.
Install

Get started now.

Requires Go 1.21+. Works on Linux, macOS, and WSL.

$ go install github.com/Platon223/Grail@latest

$ grail auth && grail inbox

Or download a prebuilt binary from the releases page ↗
